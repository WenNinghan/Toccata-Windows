# Toccata Windows Preview

发布准备日期：2026-10-29。非官方 Windows 移植预览，基于 [KMnO4-zx/Toccata](https://github.com/KMnO4-zx/Toccata) 0.1.0，基线提交 `4e3f89e4ceee03033e49722d162158f51bbea743`。当前程序内部版本仍为 0.1.0；Preview 是本移植的交付状态，不是已完成全部验收的正式版。

截图来自关闭真实采集的隔离演示环境；正常启动程序会开始记录。深色英文示例见[另一张演示截图](images/windows-preview-dark.png)。

## 能做什么

- 任务与收集箱、子任务、优先级、Markdown 详情、计划日期、任务日历、回顾与复制。
- Windows 原生窗口与系统托盘，关闭窗口收起到托盘，任务自动保存。
- 普通按键、修饰键、导航区与小键盘采集、长按重复过滤、活跃时间线、热图、应用排行和图片分享。
- 68/84/87/104 键代表性布局及位置、尺寸、标签自定义；深浅主题和中英文界面。
- Windows 第三指标为平均击键频率，按有效按键次数除以活跃分钟计算；替代上游 Fn 语音时长估算。

## 首次使用

1. 已验证环境为 **Windows 11 x64**。其他 Windows 版本、ARM64、多显示器动态缩放尚未完整验收。
2. 将整个 ZIP 解压到可写文件夹，例如非系统盘。不要在压缩包里直接运行，也不要只复制一个 EXE。
3. 运行程序子目录里的 `Toccata.exe`。无需另装 Node.js 或 GCC；这些只用于源码开发。本预览未签名，Windows 可能提示来源未知。
4. **正常启动即开始记录键盘活动**。点击窗口关闭按钮只是收起到托盘，仍继续记录；要停止记录，请在系统托盘右键 Toccata，选择“退出 Toccata”。当前没有界面内的暂停开关。
5. 添加任务：输入名称后点击加号、提交箭头或按 Enter。任务详情使用自动保存，留意“已保存”状态。

## 数据、备份与升级

程序会记录物理按键代码、时间、按住时长和前台应用归属，保存在本地。它不直接保存输入的文字，也不截图或录音，但**按键序列仍可能透露输入内容**。不要把自己的运行数据作为演示数据上传或分享；输入不希望被记录的内容之前可先退出程序。

数据文件夹位于程序文件夹的上一级，名称为 `Toccata-data`。例如 `Toccata-Windows-preview/Toccata/Toccata.exe` 使用 `Toccata-Windows-preview/Toccata-data`。它包含任务、按键记录、自定义布局、设置、应用身份及密钥，应作为一个整体备份。

- **备份**：从托盘退出后，完整复制 `Toccata-data` 到自己的备份位置。
- **升级**：从托盘退出后，只替换 `Toccata` 程序子目录，保留同级 `Toccata-data`。如果换了整个解压目录，请在首次启动前把旧数据文件夹完整复制到新位置。
- **移除程序**：退出后可删除程序目录；数据单独保留。确认不再需要记录时，再自行处理数据文件夹。

当前内置更新检查仍指向上游，且不会识别本移植的预发布 ZIP。**此预览包采用手动下载更新**。采集过程不上传记录；用户手动点击“检查更新”时会向 GitHub 请求发布元数据。

## 已知问题和差异

| 项目 | 当前状态或临时操作 |
|---|---|
| 应用图标 | 优先读取程序或 Windows 安装包的高清资源；旧缓存会在再次使用对应应用时更新。历史应用若已卸载或不再运行，无法仅凭匿名身份恢复图标；源程序素材分辨率也会限制清晰度。 |
| 排序 | 普通列表的已完成任务按创建时间排序；子任务在主列表与详情中默认顺序有差异。 |
| 保存与父任务导航 | 自动保存可用；专用保存按钮/Ctrl+S、子任务顶部返回父任务入口尚缺。可在左侧树选择父任务。 |
| 音效和拖拽 | 快速连续完成时音效可叠加；重排可保存，但缺拖拽把手和插入位置提示。 |
| 特殊键 | 不虚构 Fn 事件；Pause 未映射，部分 Print Screen/媒体键待实机验证。预设不代表自动识别全部键盘硬件。 |
| 应用排行 | 页面会加入未松开的实时长按，分享使用已提交快照；与原版应用排行口径有差异。 |
| 大量历史记录 | 尚无原版的按天统计缓存，长期数据量下的时延与内存需要规模验证。 |
| 系统行为 | 锁屏、会话切换、UAC、多设备复杂组合、长时间运行及多屏动态 DPI 尚未完整验收。 |
| 其他 | Mac 历史库没有自动导入；部分英文界面仍保留中文预设名称。 |

本预览不标注“100% 功能对齐”或“完整稳定”。反馈问题时请提供操作步骤、系统版本、主题/缩放和截图；分享截图或日志前自行检查私人内容，**不要直接提交日常数据库或 `app-identity.key`**。

## 验证与开发

已有验证包括隔离任务持久化、合成事件贯通、分享计算、实时更新、部分原生窗口/托盘工作流、浅深主题与 150% 窄窗。平均击键频率改动的相关测试为 12 项通过；最终打包程序通过启动、写入、退出、重启持久化检查。这些结果不能替代全部实体硬件和长期运行验收。

源码及已验证工具链见 [Windows 开发说明](../apps/toccata-windows/README.md)。部分测试仍使用本机 G 盘目录，公开源码的测试可移植性待补；完整并行测试有过退出等待超时，原因尚未确定。
